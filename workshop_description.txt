[h2]Overview[/h2]
Enhance your foraging experience with a detailed and customizable tooltip that provides a clear breakdown of all modifiers affecting your search radius. This mod is designed to help you understand and improve your foraging performance.

[h2]Understanding Foraging Mechanics[/h2]
The foraging system operates on two key metrics that work together:

[h3]Search Radius[/h3]
This is the glowing overlay area around your character where foraging items can potentially spawn when Search Mode is enabled. The vanilla game shows this visually but doesn't provide detailed information about what affects it.
[list]
[*] [b]What it does:[/b] Determines the area where forage icons can appear
[*] [b]Base range:[/b] 3-10 squares, extendable to 15 with bonuses
[*] [b]Visual indicator:[/b] The glowing search overlay circle
[/list]

[h3]Items View Distance[/h3]
This determines how close you need to be to individual items within your search radius to actually spot them. [b]The vanilla game doesn't show this information at all.[/b]
[list]
[*] [b]What it does:[/b] Controls detection range for each specific item within the search radius
[*] [b]Key difference:[/b] Each item type has different spot distances based on size and category
[*] [b]Item Size Impact:[/b] Item size (equal to item weight) has a huge impact - heavy items like logs and large stones get a x2.8 boost (easily spotted from distance), while small lightweight items like herbs or mushrooms get a x1.8 penalty (require being very close to spot)
[*] [b]Important Note:[/b] A big search radius doesn't guarantee detection of small items - but the tooltip will show you exactly how close you need to be to spot them
[*] [b]Tooltip Display:[/b] Currently shows base items view distance, which already includes all applied body state, weather, and other global modifiers. Category-specific bonuses (like Mushrooms % bonus) are added in addition to this base distance
[*] [b]Unique modifiers:[/b] Includes hunger bonuses for food detection (affects only items view distance for edible categories, has no impact on search radius) and extra darkness penalties
[/list]

Both metrics share most modifiers (skills, traits, weather, lighting, equipment), but view distance has additional item-specific factors that affect your success rate. Additionally, most bonuses under [b]"Trait and Profession Bonuses"[/b] (like Berries, Mushrooms, Medical Plants bonuses) apply only to Items View Distance.

[h2]Key Features[/h2]
[list]
[*] [b]Detailed Modifier Breakdown:[/b] Displays the exact effects of weather, darkness, exhaustion, and other modifiers on your search radius.
[*] [b]Items View Distance:[/b] Shows an estimated distance you need to be from items to detect them, based on your current search radius.
[*] [b]Customizable Tooltip:[/b] Tailor the tooltip to your preferences using Mod Options, enabling or disabling sections such as a formula, minimum/maximum values, and zero-value modifiers and bonuses.
[*] [b]Live Game Data:[/b] Relies on in-game calculations and values used in the vanilla tooltip, ensuring compatibility with other mods (unless they modify the same tooltip).
[*] [b]Actionable Insights:[/b] Learn how to actively improve your search radius through traits, skills, and avoiding penalties.
[*] [b]Highlights Min/Max Caps:[/b] Shows the game's minimum and maximum caps for search radius values, helping you understand modifier limits.
[*] [b]Category Visibility:[/b] Provides a comprehensive loot chance breakdown, including zero-bonus categories (optional), helping you identify items with better chances of discovery.
[*] [b]Clear Negative Modifiers:[/b] Highlights penalties in red for quick and easy identification, ensuring you can address negative impacts effectively.
[/list]

[h2]Mod Options[/h2]
You can customize the behavior of this mod under [b]Menu -> Options -> Mods -> Foraging Tooltip Extended[/b].

[h3]Available Options:[/h3]
[list]
[*] [b]Show Formula:[/b] Display the formula used to calculate modifiers in the tooltip.
[*] [b]Show Min/Max Values:[/b] Show the game's minimum and maximum caps for search radius values.
[*] [b]Show Vision Bonus Details:[/b] Display vision bonus details, which are based on crouching or aiming.
[*] [b]Show Zero Penalties:[/b] Include penalties with no impact on the search radius (multipliers x1).
[*] [b]Show Food Detection When Well-Fed:[/b] Display the food detection section even when hunger bonus is 0% (disabled by default).
[*] [b]Show Items View Distance:[/b] Display an estimated distance you need to be from items to detect them.
[*] [b]Show Zero Trait Bonuses:[/b] Include trait/profession bonuses with a value of 0 in the tooltip.
[/list]

[h2]Why Use This Mod?[/h2]
The default tooltip in the base game doesn't show much helpful information. This mod aims to show everything that affects your foraging vision and explains it clearly, though it may still miss some modifiers with plans to add them over time. It helps you understand what works and what doesn't, allowing you to get more from the foraging.

[h2]Why I Made This?[/h2]
I created this mod because I’ve always enjoyed the foraging system as a reliable source of food and medical herbs since the early versions of Project Zomboid. However, the vanilla foraging tooltip in Build 42 felt confusing in some aspects — for example, the negative Weather Effect displayed as a red value at the top of the tooltip, while also appearing in the bonuses section as a green negative value. This dual representation made it unclear how modifiers interact.

Additionally, I couldn’t find any working mods for Build 42 that addressed these issues, so I decided to create my own solution.

[h2]Compatibility[/h2]
This mod should be compatible with any other mod unless they modify the same "Vision Effectiveness" tooltip. If you encounter any incompatible mods, please let me know so I can update this list.

[h3]Incompatible Mods:[/h3]
[list]
[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3456471959][Build 42 Updated] Display All Foraging Effects[/url] - [i]This mod serves the same purpose but for me it has been broken since Build 42.8. Unlike this mod, it mimics vanilla game calculations and UI elements, making it complex to maintain, prone to inaccuracies, and vulnerable to breaking with game updates. Since both mods provide the same information, there's no need to use them together.[/i]
[/list]
